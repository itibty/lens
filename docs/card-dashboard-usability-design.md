# Lens 卡片与看板易用性改进方案

状态：已实施，2026-09-17 完成自动化检查与本地浏览器验证。

## 1. 目标与判断标准

项目当前以实验研究为主。本轮选择五项能直接改善制图体验、实现集中、容易验证及单独撤回的功能：

1. 柱状图、折线图、普通表格切换时保留字段配置。
2. 系列颜色、线型、线宽和数据点设置。
3. 坐标轴标题、上下限和零点设置。
4. 按系列控制数据标签。
5. 看板内单独设置卡片标题、备注。

“风险可控”指逻辑简单、影响面清晰、结果容易判断。无需为历史配置建设迁移或多版本兼容机制；允许直接调整现有配置结构及实验数据。

实施以现有查询、图表渲染和看板编辑流程为基础，避免引入通用规则引擎。每项独立验收，发现收益不足时可以单独移除。

## 2. 范围总览

| 功能 | 本轮范围 | 验证收益的例子 |
| --- | --- | --- |
| 图表切换 | `bar`、`line`、`table` 三种类型互转 | 配好月份、营收和成本后，反复试柱图、折线图、表格 |
| 系列样式 | `bar`、`line`、`combo`；多指标系列和第二维度产生的分类系列 | 营收固定蓝色，成本固定橙色；目标用虚线 |
| 坐标轴 | `bar`、`line`、`combo` 的类目轴和主／副数值轴 | 设置“营收（元）”、限制完成率范围、查看小幅波动 |
| 系列标签 | 与系列样式相同的三类图 | 三条线只显示重点指标的数据标签 |
| 看板局部文案 | 普通卡片、平铺组、Tab 组中的卡片 | 同一张卡片在两个看板里分别使用不同标题和备注 |

组合图加入样式增强，但本轮不纳入图表类型互转。其他图表、新计算能力、页面级 Tab、卡片多实例、图例选择持久化不在本轮范围内。

## 3. 图表切换保留配置

### 3.1 用户操作

在现有图表类型选择器里切换，不增加新按钮或转换向导。

| 切换 | 行为 |
| --- | --- |
| 柱状图 ↔ 折线图 | 保留查询配置和可用于目标图表的展示设置 |
| 柱状图／折线图 → 表格 | 保留维度、指标和查询条件；表格采用自己的默认展示 |
| 表格 → 柱状图／折线图 | 保留字段，按目标类型校验；不满足要求时标出需要调整的位置 |
| 涉及其他类型 | 保留现有转换流程，本轮不扩展所有类型之间的规则 |

保留内容包括数据集、维度、指标及公式、日期粒度、行级筛选、模板参数、聚合后筛选、结果筛选、排序、行数限制、日期基准，以及仍有效的数字格式。

### 3.2 不满足目标图表要求时

例如表格有过多维度，或者包含目标图不支持的同环比指标：

- 允许切到目标类型，保留原字段和计算定义。
- 沿用字段区域的错误定位，提示“折线图最多支持……”“当前图表不支持同环比”等具体问题。
- 清除上一类型的预览，配置有效后才能运行／保存，避免把旧结果呈现为新图的有效结果。
- 用户可自行调整，也可以切回表格；切回后字段仍在。

有效转换不再出现“将清空维度、指标”的确认。转换不隐式删除查询字段、不将对比指标改成普通指标。

### 3.3 展示配置的处理

- 卡片标题、备注、数字格式等公共设置保留。
- 柱图和折线图可以共用系列颜色等设置；线型等字段只在适用的几何类型上生效。
- 表格采用表格展示配置。本轮保证查询配置保留，不建设按图表类型保存多套历史样式的机制。
- 类型转换中不改指标别名、不重新生成已有字段的编辑标识，避免格式配置和排序引用丢失。

### 3.4 实现落点

在 `cards/chartShape.ts` 或相邻小模块中提供一个三类型转换函数，供 `cards/edit.vue` 调用。先生成待应用配置，再复用 `collectQueryIssues` 校验；检查现有深度 watcher，避免它们在中间状态提前删除依赖项。

不修改 SQL 生成、查询服务或指标计算规则。测试同时比较转换前后的查询配置，确认转换没有悄悄改变数据含义。

## 4. 系列样式与数据标签

第 2、4 项使用同一套系列选择和设置界面，作为一个实现单元。

### 4.1 界面

在卡片现有“样式”中新增“系列”区域：

1. 选择系列，例如“营收”“成本”或“直营”“加盟”。
2. 显示该系列适用的设置。
3. 提供“恢复默认”，仅清除所选系列的覆盖配置。

| 设置 | 可选值 | 适用范围 |
| --- | --- | --- |
| 颜色 | 色板 + 自定义色 | 柱、线、组合图中的实际系列 |
| 线型 | 实线、虚线、点线 | 折线及组合图中的折线系列 |
| 线宽 | 细、标准、粗 | 折线及组合图中的折线系列 |
| 数据点 | 自动、显示、隐藏 | 折线及组合图中的折线系列 |
| 数据标签 | 跟随整体、显示、隐藏 | 柱、线、组合图中的实际系列 |

沿用现有“数据标签”整体开关，单系列配置优先于整体开关。标签数值格式继续复用指标格式，不另建标签格式体系。

同一界面只显示适用项。例如组合图中选择柱系列时，不出现线型和数据点选项。

### 4.2 系列身份

系列设置不能绑定数组下标，避免排序、筛选后颜色和标签跑到别的系列上。

- 多指标系列：使用当前查询输出的指标别名标识；编辑器改名时同步更新系列配置。结果列别名的唯一性沿用现有校验。
- 第二维度产生的分类系列：使用维度字段标识和规范化的分类值；键编码区分值类型，不用图例显示顺序。
- 单指标无分类时，也提供该指标的一个可配置系列。
- 指标改名、删除的处理集中到小型同步函数；不为此引入全项目统一标识重构。
- 分类候选来自当前已查询结果及已有配置。筛选后某分类暂时没有数据，保留其设置，供后续再次出现时使用。
- 删除指标／更换系列维度时，清理对应无效规则。修改默认色板不覆盖显式指定的颜色。

采用 `visual.chart` 下的独立系列配置，具体字段名在实施时确定。新增设置与现有数字格式的匹配方式可以共享工具，但不能直接使用会把不同公式指标合并的粗粒度键。

### 4.3 渲染规则

- 指定颜色同时用于图形、图例和 Tooltip 色标。
- 组合图根据最终柱／线分配应用适用样式，切换系列几何类型不会把虚线配置应用到柱形上。
- 标签继续保留现有避让和数值格式逻辑，过密时允许图表库隐藏重叠标签。
- 显示／隐藏标签只影响文字，不改变图形、查询结果、合计和导出数据。
- 样式修改应立即更新预览；恢复默认后不得残留旧颜色、虚线或数据点。

实现前用当前项目已安装的 VChart 版本验证多指标、分类系列和组合图的样式映射。优先使用现有 spec 和样式回调，避免为了控制每条线而重建整套图表渲染架构。

## 5. 坐标轴设置

### 5.1 界面

在现有“功能设置”中新增“坐标轴”区域：类目轴、主数值轴，使用双轴时再显示副数值轴。

- 类目轴：标题显示开关、自定义标题。
- 数值轴：标题显示开关、自定义标题、最小值、最大值、零点策略。
- 上下限输入为空表示自动；标题为空时使用图表默认标题。
- 零点策略：自动、包含零点、按数据范围。仅在上下限都为自动时可设置。
- 单独提供恢复默认。

第一版的单位通过轴标题及现有指标格式表达，例如“营收（元）”；不增加第二套数值单位换算规则。

### 5.2 明确语义

- 范围使用原始查询数值。比如原值 10000，紧凑显示为“1 万”，输入上限仍是 10000。
- 两个边界都填写时必须是有限数值，且最小值小于最大值；无效草稿显示字段错误，不提交给渲染器。
- 手动上下限优先；仅填写一侧时，另一侧自动计算。
- “包含零点”表示自动范围覆盖 0，负数不会因此被裁掉。
- “按数据范围”取消强制包含 0，仍由图表库确定具体边界。
- 主／副轴分别控制分配给自己的指标，不因为新增设置创建没有指标的空轴。
- 横向柱图按“类目轴／数值轴”映射到实际方向，不能把设置固定套到物理 X／Y 轴。
- 百分比堆叠沿用 0%～100% 的范围，本轮只允许改标题，范围和零点设置不生效且不展示可编辑控件。
- 明确填写的范围可能裁掉范围外图形，这是展示选择；Tooltip、原始结果和导出数据不做相应过滤。

### 5.3 实现落点

在 `cardRenderer.ts` 已有坐标轴构造完成后，应用一层集中的轴配置映射。范围校验、默认值解析放到独立小模块，不改查询结果或日期分组。

优先验证取消手动范围后轴能恢复自动；确需重建 VChart 实例时，只将对应结构变化纳入现有实例重建判定，不对所有样式修改无条件重建。

## 6. 看板内卡片标题与备注

### 6.1 入口与操作

看板编辑态的卡片 More 中增加“显示设置”。现有打开共享卡片编辑器的操作命名为“编辑卡片”，便于辨认两种操作的作用对象。

“显示设置”使用一个小弹窗，只有标题和备注两项。每项支持：

- 跟随卡片：读取共享卡片的当前显示设置。
- 自定义：填写当前看板使用的文案，并显示该项。
- 隐藏：在当前看板隐藏该项。

默认跟随卡片；恢复默认清除当前看板对该卡片的覆盖。自定义标题最多 50 字、备注最多 200 字，使用纯文本；自定义模式空白时提示填写或切回跟随。

弹窗确认只更新看板编辑草稿，点击“保存看板”后生效。查看态不新增常驻入口或说明文字。

### 6.2 存储与显示

利用当前“看板内同一卡片只出现一次”的规则，在看板 `configJson` 中增加按卡片 ID 索引的 `cardDisplayOverrides`。不把设置写回共享卡片，也不引入卡片实例 ID。

建议的最小结构：

```json
{
  "cardDisplayOverrides": {
    "9208": {
      "title": "华东销售趋势",
      "description": null
    }
  }
}
```

- 字段缺省：跟随卡片。
- 非空字符串：自定义并显示。
- `null`：隐藏。

解析层为此字段增加明确类型、清洗和校验，不长期借用 `extra` 作为无类型配置桶。后端保存时校验卡片成员、类型和长度，避免只有前端约束。

### 6.3 边界

- 卡片移入／移出分组、切换平铺／Tab 后，局部设置跟随卡片保留。
- 从看板移除卡片时删除对应覆盖，重新添加时从跟随卡片开始。
- 分组“隐藏子卡片标题”仍具有布局上的优先级；卡片进入全屏后的行为沿用现有标题规则。
- Tab 标签继续由分组的 Tab 标题决定，局部卡片标题不修改 Tab 标签或分组名称。
- 原卡片编辑器、其他看板均保持自己的显示内容。
- 查看页、独立预览、卡片全屏、截图和订阅截图采用同一份显示配置；邮件主题仍使用看板／订阅名称。
- 修改标题和备注不触发数据重查，不改变卡片 ID、查询、筛选、个人视图、下载数据或权限。

在 `DashCardTile` 为展示计算临时的有效文案／visual，不修改传入的 `card` 对象。查询侧继续读取原卡片配置。根 `DashGrid` 通过 provide/inject 提供覆盖配置与编辑入口，统一覆盖普通卡片、平铺组、Tab 组以及流式布局分支。

## 7. 代码落点与控制方式

| 部分 | 主要文件／模块 | 原则 |
| --- | --- | --- |
| 图表转换 | `cards/edit.vue`、`cards/chartShape.ts` | 三类型纯转换，复用现有查询校验 |
| 配置模型 | `shared/types.ts`、`shared/chartOptions.ts` | 复用现有 JSON，默认值和清洗集中 |
| 系列设置 | `charts/style-forms`、小型系列解析模块 | 一个系列入口合并颜色、线型和标签 |
| 渲染 | `shared/cardRenderer.ts`、`shared/VChartHost.vue` | 构造现有 spec 后应用设置，核验重置行为 |
| 看板覆盖 | `dashConfigCodec.ts`、`dashboardRepository.ts`、`DashDesigner` 与各网格组件 | 按卡片 ID 保存，统一传递，展示和查询分开 |
| 看板配置校验 | 后端看板配置准备／保存层 | 只校验新增展示字段及成员关系 |

本轮配置保存在现有 JSON 中，无需新增数据库表或字段。公开 API DTO 未变更，无需重新生成 API 客户端。

无需历史数据迁移方案。开发中可直接调整演示配置，最终只保留一套明确的数据模型。

## 8. 实施顺序

按一个版本、四个独立改动完成；每步验证后再进入下一步。

### A. 图表切换

完成三类型转换、错误定位和字段保留，先验证最直接的制图收益。

### B. 系列样式与标签

先验证 VChart 的实际系列映射，再接设置表单、保存和重置。覆盖颜色、线型、线宽、数据点及按系列标签。

### C. 坐标轴

接入轴标题、范围和零点策略，集中验证横向、双轴及百分比模式。

### D. 看板局部文案

接入显示设置弹窗、存储和全部看板展示分支，验证共享卡片不被修改。

每个改动尽量形成独立提交。移除某个实验功能时，可以撤去相应表单和配置映射，不需要拆除公共查询引擎或改变布局标识体系。

## 9. 验收方案

使用少量专门的实验卡片，覆盖以下案例：

| 案例 | 通过标准 |
| --- | --- |
| 月份 + 营收 + 成本，柱 → 线 → 表 → 柱 | 字段、公式、筛选、排序和数字格式仍在，计算结果一致 |
| 含同环比／过多维度的表格转折线图 | 保留配置并定位问题，不发无效查询、不静默删除字段 |
| 多指标重新排序或改名 | 显式系列颜色、标签等仍对应正确指标 |
| 渠道分类筛选后消失再出现 | 已配置颜色仍对应原分类，图例和 Tooltip 色标一致 |
| 组合图的柱／线、主／副轴 | 设置只作用于对应系列与轴，无错误交叉应用 |
| 标签整体关闭，单系列开启 | 只显示指定系列，数值格式正确 |
| 范围设置后清空、切换方向、恢复默认 | 自动范围正常恢复，无上一状态残留 |
| 负值、全零、空结果、百分比堆叠 | 轴与图形含义明确，无非法范围或崩溃 |
| 同一卡片出现在两个看板 | 一个看板修改文案，另一个看板和原卡片不变 |
| 卡片在根网格、平铺组、Tab 组间移动 | 局部文案正确保留，移除后清理 |
| 查看、全屏、独立预览、移动端、截图 | 新样式和局部文案一致；修改文案不增加查询 |
| 看板保存并重新打开 | 覆盖模式、空值语义和样式设置均正常恢复 |

自动化测试集中在转换的查询保留、系列身份与重命名、配置优先级、坐标轴映射和看板配置编解码。无需给每个低影响的样式控件写重复实现的测试。

实施阶段执行前端 `pnpm lint`、`pnpm type-check`、相关测试及生产构建；后端配置校验有改动则执行 `mvn test`。最终用浏览器验证真实渲染和截图，订阅截图可沿用运行入口验证，不需要实际发送邮件。

## 10. 完成标准

五项都能通过原有编辑入口使用，保存重开可复现。类型切换保留数据配置，展示设置不改变查询结果，局部文案不修改共享卡片。
