# Lens 复制与复用

日期：2026-09-17
状态：已实施并验证

## 1. 目标

让分析人员基于已有卡片和看板快速制作变体。本期提供卡片复制、卡片另存为、看板复制，沿用现有编辑与保存入口。

## 2. 卡片

### 列表复制

- 卡片列表操作区增加“复制”，仅有卡片配置权限时展示。
- 打开设计器的新草稿，地址使用 `copyFrom` 指向源卡片；读取源卡片后立即清除草稿中的实体 ID 和更新时间。
- 名称默认为“原名称 · 副本”，总长度不超过 50；描述、状态、数据集、查询、明细和展示配置保留。
- 点击保存才创建新记录，取消或离开不会产生空副本。复制草稿具有未保存提示。
- 卡片与源卡片独立编辑，继续引用原数据集；新卡片没有任何看板引用。

### 编辑器另存为

- 已保存卡片的保存按钮旁提供“另存为”，复用保存弹窗。
- 保存当前草稿，包含尚未保存的修改；弹窗取消保持当前草稿。
- 新建请求不包含源卡片 ID，不先保存原卡片。成功后切换到新卡片，后续保存更新新卡片。
- 校验失败或请求失败时停留原卡片，保留草稿和弹窗内容；提交期间防止重复点击。
- 列表复制与另存为沿用图表、字段、明细及名称的现有校验。禁用卡片保留禁用状态；数据集失效时按原保存规则提示修正。

## 3. 看板

### 入口与流程

- 管理树的看板 More 中增加“复制”。复制已保存的看板配置，不读取设计器未保存的布局。
- 复用看板信息弹窗，名称默认“原名称 · 副本”；可修改分组、描述、图标和状态。
- 弹窗用一行说明表达实际影响：**复制已保存的配置，复用原卡片；卡片修改同步生效。**
- 提交前沿用未保存修改确认；取消确认不创建副本。
- 提交时重新读取源看板，确认仍存在且可访问。成功后刷新目录并打开新看板。

### 复制范围

| 内容 | 规则 |
| --- | --- |
| 看板名称、描述、图标、状态、分组 | 预填源配置，允许修改 |
| 布局、文本、平铺组、Tab、局部标题与备注 | 复制，随后独立编辑 |
| 筛选定义、默认值、主题、刷新周期 | 复制 |
| 卡片 | 保留原 ID，复用共享卡片，不新增卡片 |
| 布局节点与筛选 ID | 在新看板内保留，作用域由新看板 ID 隔离 |
| 已删除卡片 | 按后端成员列表清理对应布局及局部覆盖；禁用卡片保留 |
| 用户／角色授权、订阅、收藏、访问记录、个人视图 | 新看板按新建规则处理，复制请求不包含这些关系 |

不提供“连同全部卡片复制”或替换数据集，避免引入卡片映射与筛选重绑规则。

## 4. 实现

- 前端小型纯函数负责默认副本名、卡片草稿复制，深复制配置以隔离引用。
- 卡片复用 `fromVisCardInfo`、查询校验和 `toVisCardSaveRequest`。构建保存请求时不修改编辑中的 visual。
- 看板复用 `dashboardRepository`、配置编解码与保存接口；不加载全部卡片详情，不以详情请求失败判断卡片已删除。
- 后端沿用正常新增流程生成 ID、维护成员关系、检查权限及事务；公开 API 和 DDL 均不变。
- 页面操作保留加载状态、失败提示、取消行为和未保存保护，不引入复制任务或新页面。

## 5. 验收

1. 卡片复制后修改筛选、样式并保存：新 ID，源卡片配置和原看板成员不变。
2. 另存为保留未保存修改；成功切到新卡片，再次保存更新新卡片而非源卡片。
3. 取消、空白名称、无效图表和失败请求均不误创建、不覆盖原卡片。
4. 普通图、表格、透视表和静态卡复用完整配置；长名称不超限。
5. 看板复制后布局、Tab、筛选和局部覆盖一致，卡片 ID 不变；修改新看板布局与文案不影响原看板。
6. 新看板没有复制原授权、订阅或个人状态。已删除成员清理，禁用成员保留。
7. 无权限入口隐藏，接口继续执行原有权限校验；源对象不存在时显示失败。
8. 自动化验证复制隔离与保存请求语义，执行前端 lint、类型检查、测试和构建；浏览器验证真实复制、另存为、取消、保存重开，并检查数据库中的实体及关系。

## 6. 验证记录

- 前端 `pnpm lint`、类型检查和生产构建通过；26 个测试文件、202 项测试通过。
- 复盘整理：看板新增与复制共用保存入口，表单提交统一使用 `async/await` 与 `finally`；卡片是否已保存直接由 ID 判断，减少重复状态。
- 浏览器验证：列表复制生成新草稿、空白名称校验、未保存保护、另存为取消保留草稿、另存为携带查询修改、成功切换新 ID、后续保存更新副本。
- 看板验证：管理树复制入口、共享关系提示、筛选默认值、平铺组与 Tab、局部标题复制、取消不创建、保存重开及原看板文案隔离。
- API 与数据库核对：原卡片仍保留 8 行查询，另存副本保存 5 行；新卡片没有看板引用；新看板卡片 ID 与原看板一致，授权、订阅、收藏／访问偏好、个人视图关系为空。
- 复制保存沿用布局规范化：平铺组未使用的页标题会清理，空分组备注采用现有默认值；有效布局和 Tab 标题保留。
- 整理后重新通过前端全量检查，浏览器补测看板新增、空白名称校验、元信息编辑、复制与取消，并核对保存数据。两条临时看板已清理。
- 本期无新增后端接口、DDL 或生成 API 变更。临时验证数据已清理，开发服务继续运行以便体验。
