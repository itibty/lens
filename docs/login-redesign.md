# Lens 登录页设计稿

只出图，不改代码。共 **80** 张，都在下面，按编号往下翻即可。

原图：[`design-previews/login/`](design-previews/login/)

三轮方向不一样：

| 轮次 | 编号 | 在干什么 |
| --- | --- | --- |
| 一 | 01–10 | 电影、光效，容易炫 |
| 二 | 11–60 | 克制、留白，有的不像系统 |
| **三** | **61–80** | **现代 IT / SaaS 登录。大气、有腔调，但一眼仍是软件** |

建议先看 **61、66、71、76、79**。

---

## 第三轮 · 系统登录（61–80）先看

#### 61 产品分屏

左驾驶舱预览，右白表单。还是现在的左右结构，左边换成真系统。

![61 产品分屏](design-previews/login/login-61-product-split.png)

#### 62 先进入产品壳

顶栏已经是 Lens，中间弹登录窗。像打开系统后要鉴权。

![62 先进入产品壳](design-previews/login/login-62-app-chrome.png)

#### 63 深色控制台

左侧图标栏 + 状态条。控制台，不是海报。

![63 深色控制台](design-previews/login/login-63-console.png)

#### 64 进入工作区

浅色 SaaS。「进入工作区」当标题，表单是真控件。

![64 进入工作区](design-previews/login/login-64-workspace-light.png)

#### 65 空画布

侧栏和卡片虚线已经在，登录卡浮在空驾驶舱上。

![65 空画布](design-previews/login/login-65-empty-canvas.png)

#### 66 模糊驾驶舱

背后是产品，前面一张登录卡。SaaS 经典，腔调来自产品自己。

![66 模糊驾驶舱](design-previews/login/login-66-blur-dash.png)

#### 67 左侧栏路由

侧栏锁住，主区是 `/login` 设置页式表单。

![67 左侧栏路由](design-previews/login/login-67-left-rail.png)

#### 68 深色产品壳

整页用现有顶栏那套深色。表单小，页脚是系统链。

![68 深色产品壳](design-previews/login/login-68-dark-shell.png)

#### 69 桌面应用窗

标题栏 + 窗口。软件，不是网站海报。

![69 桌面应用窗](design-previews/login/login-69-desktop-app.png)

#### 70 轻网格底

冷色 mesh + 居中白卡。现代 SaaS，不是星云。

![70 轻网格底](design-previews/login/login-70-saas-mesh.png)

#### 71 品牌功能栏

左栏写清 数据集 / 卡片 / 仪表盘，右栏登录。企业产品常见结构。

![71 品牌功能栏](design-previews/login/login-71-brand-pane.png)

#### 72 后台中心

灰底、顶条品牌蓝、系统登录。中国企业后台，间距更讲究。

![72 后台中心](design-previews/login/login-72-admin-center.png)

#### 73 深色青绿点

深底、服务可用、版本号。控制台腔调，仍是网页表单。

![73 深色青绿点](design-previews/login/login-73-dark-teal.png)

#### 74 浏览器里

地址栏就是 `/login`。提醒这是系统，不是视觉装置。

![74 浏览器里](design-previews/login/login-74-browser-frame.png)

#### 75 平台登录

「登录 Lens」+ 工作区芯片 + SSO/审计提示。

![75 平台登录](design-previews/login/login-75-enter-workspace.png)

#### 76 现结构升级

还是居中大卡左右分。左边卡通欢迎换成驾驶舱。

![76 现结构升级](design-previews/login/login-76-card-upgrade.png)

#### 77 企业 SSO

标准卡 +「或使用企业身份」。像身份系统。

![77 企业 SSO](design-previews/login/login-77-sso.png)

#### 78 顶栏条

先看到产品顶栏，再落到登录卡。

![78 顶栏条](design-previews/login/login-78-top-strip.png)

#### 79 右侧抽屉

驾驶舱在，登录从右边滑出来。最像「系统要你登录」。

![79 右侧抽屉](design-previews/login/login-79-docked-drawer.png)

#### 80 平台卡

居中大卡，副标题「数据集 · 卡片 · 仪表盘」。软件身份清楚。

![80 平台卡](design-previews/login/login-80-platform.png)

## 怎么挑

| 你要的 | 先看 |
| --- | --- |
| 一眼就是 Lens 这套系统 | **61、66、76、79** |
| 现代 SaaS，有点腔调 | **64、70、71、75、80** |
| 深色控制台 | **63、68、73** |
| 改动最小（现结构升级） | **76、61** |
| 海报感强、不太像系统 | 01–10、以及 20、30、36、40 附近 |

选中编号后，再改 `frontend/src/views/login/index.vue`。
