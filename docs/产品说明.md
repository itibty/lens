# Lens

用 SQL 收数，做成卡片，拼成看板。演示数据是「启明零售」全渠道订单。

```text
数据集 → 卡片 → 看板 → 报表中心
```

## 数据集

一段只读 SQL 就是一个数据集。列绑定成维度或指标，后面做图都从这里拖。

![数据集](images/03-datasets.png)

脚本可带参数（大区、渠道、日期），看板筛选会灌进来。

![SQL](images/04-dataset-sql.png)

![字段](images/05-dataset-fields.png)

## 卡片

选数据集、选图种，把字段拖到维度 / 指标 / 筛选上，右侧即时预览。一张卡只回答一个问题，可以挂到多块看板。

![卡片列表](images/06-cards.png)

指标卡看当期和同环比。

![指标卡](images/07-card-number.png)

折线看走势，透视看交叉。

![折线](images/08-card-line.png)

![透视](images/09-card-table.png)

图种按用途分：指标、对比、趋势、构成、关系、表格。另有词云、文本、外链。

## 看板

把卡片铺到网格上，顶栏放大区、渠道这类全局筛选，一次作用到整页。

![看板设计](images/10-dashboard-designer.png)

![全屏预览](images/12-dashboard-preview.png)

## 报表中心

业务入口。只出现当前角色能看的看板，筛选、刷新即可，没有设计按钮。

![经营驾驶舱](images/13-report-center.png)
