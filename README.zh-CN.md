# Lens

[English](README.md) | [中文](README.zh-CN.md)

**从一段 SQL，到团队每天都能用的数据看板。**

Lens 是一个轻量级开源 BI 平台，适合经营、销售和增长分析。把关键指标放在一起，看清变化与原因，让团队随时了解业务进展。

[开始使用](docs/getting-started.zh-CN.md) · [查看完整演示](docs/product.md)

![Lens 零售增长驾驶舱：营收、订单、销售趋势、渠道贡献与区域排行](docs/images/showcase-retail-growth.jpg)

## 让数据用起来

- **一眼看清业务。** 把指标、趋势、排行和转化漏斗组合成看板，既看结果，也看原因。
- **按自己的问题分析。** 从 SQL 数据集出发，可视化配置图表、编排布局，搭出适合业务的报表。
- **让团队一起看。** 按角色开放报表，在电脑和手机上查看，跟进业务变化。
