# Lens 主题

- `tokens.ts` 是默认颜色、明暗表面和主题预设的来源。按用途修改语义，避免按页面新增颜色。
- `cssVars.ts` 一次性适配 `--na-*` 和 Element Plus 的 `--el-*`，在应用挂载前安装。
- 组件 CSS 使用 `var(--na-text-muted)`、`var(--na-surface-bg)` 等语义变量；继承 Element Plus 的组件也可使用对应 `--el-*`。
- 仪表盘在自己的容器上应用同一组变量。传送到 body 的弹层通过 `dashOverlayVars` 获得相同作用域，不修改根主题。
- 看板方案集中在 `tokens.ts` 的 `THEME_PRESETS`：默认、海军蓝、象牙纸、森林绿、石墨橙、深夜，以及清透玻璃、深海玻璃两种实验主题。「默认」直接复用 `LIGHT_THEME`，与卡片设计页共用文字、表头、表面和图表配色；不要另建一套相近的浅色方案。其他方案通过 `classicTheme` 指定画布、卡片、标题和系列色，`recipeColors` 统一生成交互色阶；保留已保存的 `t1`–`t6` 编号，两种玻璃方案依次使用 `t7`、`t8`。
- `LensTheme.chrome` 是独立的顶栏颜色组。`dashChromeVars` 仅作用于顶栏控件；卡片文字与表格表头由主主题提供。深色顶栏配浅色卡片时，传送到 body 的菜单通过 `dashOverlayVars` 使用主主题表面，不继承顶栏反色。
- Canvas 适配器统一接收 `ThemeColors`，省略时使用 `LIGHT_THEME`；不再混用明暗布尔值或重复的看板颜色映射，也不向 Canvas 传 CSS 变量。
- 分类、连续、发散色板有各自含义，保留 `chartPalette.ts` 中的专用色板入口；默认分类色取公共 `DATA_SERIES`。
- 默认图表通过显式开关跟随看板方案的 `chart.series`，分类顺序保持不变；默认热力图按主题主色与卡片表面生成连续色带。`VisCardView` 显式判断 `chartTheme === DEFAULT` 并传递完整颜色对象，VChart / VTable 在渲染时适配坐标轴、图例、表头和单元格。高对比 / 易辨色 / 显式渐变保持独立，自定义卡片表面保留独立配色。
- 图形的默认点径和面积填充强度在 `vchart.ts` 集中适配，显式主题和业务 spec 可覆盖；不要在页面中重复设置图表样式。
- `presentation.scss` 定义看板 / 卡片预览共用的排版、间距、控件尺寸、徽标和分段切换规范，由 `assets/styles/tokens.scss` 安装默认变量。它只供展示组件使用，不改管理表单的默认样式。
- 卡片与分组标题共用 `title`，辅助指标共用 `badge`，图标操作共用 `VisActionButton`（compact / regular / touch，ghost / outline）。需要调整密度时，在看板容器覆盖 `--vis-card-inset`、`--vis-card-header-y` 等变量；不要追加每个页面的覆盖样式。
- 卡片数据区使用中性表面，通过文字层级、留白和轻阴影区分内容，默认不描边；看板卡片、分组和卡片预览统一读取 `--vis-card-border`。经典方案协调画布、看板顶栏、卡片标题和默认数据色，象牙纸与森林绿允许轻微暖色 / 绿色卡片表面。自定义卡片背景 / 文字仍优先；辅助指标自带表面与配套文字色，避免深色卡片上的浅底标签失去对比。
- 筛选摘要共用 `filter-chip`：紧凑胶囊、无描边、浅底色；标签保持次要文字色，只用主题色强调已选值。选中、悬停与键盘焦点分别表达，避免所有文字和边框同时着色。
- 移动端展示密度由 `compact-tokens` 统一调整；简单指标相邻配对，落单指标和图表占整行，低于 360px 的容器退回单列，分组按自己的内容宽度判断。布局高度和配对规则集中在 `dashPresentation.ts`，不修改保存的桌面布局。
- 大屏顶栏让标题和说明同排，以「刷新 + 更多」收起截图、临时主题等次要操作；更多菜单跨尺寸共用，保留完整说明，小屏使用触控尺寸。独立预览页不再显示重复的「独立预览」入口，报表中心仍保留。
- 设计页顶栏的主题切换只覆盖当前画布预览，不写入配置、不触发未保存状态；配置弹窗中的主题才属于可保存草稿，确认配置主题后清除临时覆盖。
- 小屏顶栏用轻量筛选入口和可横向浏览的条件摘要，筛选面板按内容高度展开；卡片完整标题和备注收在更多菜单，避免多个操作挤占标题空间。
- 设计态辅助线由 `DashGridGuides` 共用，几何计算复用 `config.ts` 的列数、行高和间距；只读布局，分组按自己的容器宽度计算。`useDashGridGuides` 管理当前操作区域，避免内外辅助线叠加。开关只保存在浏览器，预览和截屏不包含辅助层。
- 显式保存的自定义颜色优先于主题，不根据颜色相等猜测用户意图或重写历史配置。默认值继续在渲染时补齐。
- Sass 只保留布局、字体等编译期配置，颜色不再与 TypeScript 分别维护。

新增默认颜色应先检查已有语义。富文本用户色、语法高亮、分类色板、遮罩等有明确用途的颜色可以独立定义；不要机械合并数值相同但用途不同的颜色。

数字排版使用 `views/vis/shared/VisMetricValue.vue`（数字、单位、趋势符号）、`VisMetricAux.vue`（辅助标签与数值紧凑成组，整组换行）和 `VisMetricRatio.vue`（当前值 / 目标值）。字号通过 `numberStyle.ts` / `numberFit.ts` 提供，避免各类卡片分别调整行高、单位间距和箭头位置。趋势箭头与数字处于同一行内排版上下文，使用 `cap` 字形高度单位；辅助指标统一使用公共中性填充色，涨跌色只用于数值，不扩散到背景。
